# Система заказов компании «Обувь-Маг»

**Автор:** Иванов И.И., группа ИС-21  
**Дисциплина:** Стандартизация, сертификация и техническое документирование  
**Среда разработки:** VSCodium / .NET 8 CLI  

## Описание проекта
Консольное приложение на C#, реализующее алгоритм расчёта скидки для информационной системы компании «Обувь-Маг». 
- Правило скидки: если по товару/клиенту не было заказов в прошлом месяце — предоставляется скидка **25%**.
- Код полностью задокументирован при помощи стандартных XML-комментариев (`/// <summary>`, `<param>`, `<returns>`).
